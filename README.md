# MANASSÉS.dev – Portfólio (Next.js + TypeScript)
1. `npm install`
2. `npm run setup:reactbits` (instala EchoText, AeroShards, BorderGlow, LogoLoop, CursorGrid, GlareHover, SpecularButton e AnimatedContent via shadcn/React Bits)
   - Os componentes devem ficar em `components/`. Se o CLI os colocar noutra pasta (ex.: `components/ui/`), ajuste os imports `@/components/<Nome>`.
3. `npm run dev`
4. Edite `lib/data.ts` (projetos) e o link do CTA final em `app/page.tsx` (`https://wa.me/`).
